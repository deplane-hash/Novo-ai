# Novo-ai (Nova)

Open-source AI workspace for building and publishing websites locally.

Install (Linux/macOS):

```bash
curl -fsSL https://freedomhub.at/install.sh | bash
```

Or from this repo:

```bash
npm install
npm run build
npm start
```

Dev:

```bash
npm run dev
```

API keys live in `~/.nova/config.json` on your machine — never commit them.
