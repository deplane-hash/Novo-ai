FAQ

Good to know

Does Nova delete or move my files? +

Nova never deletes anything. To deploy, it packs a copy of your folder and publishes the copy — your originals stay exactly where they are. Disabling a site removes the live copy, never your local work.

Which platforms are supported? +

Windows 10/11, macOS and Linux, on any machine with Node.js 18+. The install script handles everything else automatically.

Is there a subscription? +

The client is free forever with one hosted site included. Pro is an optional $2/month for unlimited sites — cancel anytime.

How do I get a free hosted site? +

Install Nova and run nova register. You get a free hosting token instantly. Then deploy any folder with nova deploy and it's live at yourname.freedomhub.at.

What if it's not for me? +

The core client is free — there's nothing to lose. For Pro, we offer a money-back guarantee: email us and we'll refund you, no questions asked.
